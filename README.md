# Polymarket BTC 5-minute momentum strategy

The demo bot polls a public CCXT BTC spot ticker every **500 ms** and compares the latest price with a sample about **1,000 ms earlier**. Its trigger adapts to volatility: it uses the **99th percentile of absolute one-second BTC moves** collected over a rolling window of up to **20 minutes**, with a **$1 minimum threshold**. After startup it waits for 120 valid move samples (about one minute at the default cadence); the baseline then grows to a full 20 minutes as data accumulates. The dashboard shows the current threshold and warm-up progress. Moves at or above the threshold target UP; moves at or below its negative target DOWN. It buys 500 shares of the target Polymarket outcome. On an opposite signal, it sells the held position only if its average entry fill was at or below **$0.40**; above $0.40 it holds and does not open the opposite side. If a permitted reversal only partially sells, it also waits rather than opening the new side. Repeated signals in the held direction do not add entries.

Coinbase `BTC/USD` is the default feed: it is reachable from this runtime and its CCXT rate limit permits 500 ms polling. Set `CCXT_EXCHANGE` and, if needed, `CCXT_SYMBOL` to select another CCXT market; the feed honors an exchange's higher minimum interval if it requires one. Binance returned a location restriction from this runtime, so Binance connectivity is not assumed. The dashboard reports feed errors and staleness; a missing or stale feed cannot generate a signal.

Demo marketable orders use visible Polymarket book depth and are capped at the observed best ask for buys or best bid for sells. Fills can be partial or absent. Estimated crypto taker fees are included in demo cash and P&L. A partially sold position blocks entry on the opposite side. A held-side CLOB midpoint at or above **$0.99** is counted as a $1 payout per remaining share; at or below **$0.01**, it is counted as $0.00. This is a demo threshold heuristic, not official resolution. Other shares still open at the five-minute close wait for official Polymarket resolution. Account equity is cash plus the marked value of all open shares; total P&L is equity minus starting capital, and marks remain available when the active market rolls over.

This strategy is strictly demo-only. `LIVE_TRADING=true` is refused before wallet authentication, and the active bot uses only `DemoTrader`. The $10,000 paper balance and history reset when the process restarts. Simulated fills, estimated fees, and P&L are behavior checks—not evidence of live execution or profitability.

Run `npm test` from this directory to verify the feed, adaptive threshold, order behavior, and live guard. For local startup and dashboard checks, follow `DEMO_RUNBOOK.md`.
